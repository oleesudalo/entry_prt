SW미래채움 3급 실기 문제은행 - 최종 배포본

구성
- A형 15회 × 실기 10문제 = 150문제
- B형 15회 × 실기 10문제 = 150문제
- 총 300문제
- 문제/정답 이미지, 실습파일, 오답/진도 저장 기능 포함

사용법
1. 압축을 풀고 index.html을 실행합니다.
2. 온라인 배포는 이 폴더의 내용 전체(index.html, assets, practice)를 그대로 업로드합니다.
3. Netlify Drop에서는 압축을 푼 폴더 전체를 드래그하면 됩니다.
4. GitHub Pages에서도 파일 구조를 그대로 유지하세요.

주의
- 브라우저에서 메모와 맞음/틀림 기록은 localStorage에 저장됩니다.
- 다른 브라우저/기기에서는 진도 기록이 자동 동기화되지 않습니다.
